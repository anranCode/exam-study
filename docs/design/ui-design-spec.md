# UI 设计规范

> 所有前端界面必须遵守本规范。实现时先在 `src/styles/variables.css` 定义下面的 CSS 变量,组件里只引用变量,不写死颜色和尺寸。

---

## 一、设计原则

这个工具的使用场景是**碎片时间**:通勤路上、排队时、睡前。由此推出三条原则:

1. **一屏一件事。** 一个页面只回答一个问题。今日页只回答「现在该做什么」,点进去就开始做题,不要有中间跳转。
2. **三秒可开始。** 从打开到看到第一道题不超过 2 次点击。这是设计的最高优先级。
3. **数字即反馈。** 用正确率、连续天数、剩余题量这些数字给反馈,不用徽章和动画。自用工具,数字最诚实。

明确不做:排行榜、成就徽章、分享按钮、复杂的页面过渡动画。

## 二、色彩

### 主色与语义色

| 变量 | 值 | 用途 |
|---|---|---|
| `--color-primary` | `#2F6FED` | 主操作按钮、当前选中态、进度条 |
| `--color-primary-light` | `#E8F0FE` | 主色浅底,用于选中背景 |
| `--color-success` | `#12A150` | 答对、复习完成、掌握度达标 |
| `--color-success-light` | `#E7F6EE` | 答对反馈底色 |
| `--color-danger` | `#E5484D` | 答错、到期未复习 |
| `--color-danger-light` | `#FDECEC` | 答错反馈底色 |
| `--color-warning` | `#F5A524` | 连续天数中断警告、题目待确认 |
| `--color-info` | `#6B7280` | 次要信息、未作答 |

### 中性色

| 变量 | 值 | 用途 |
|---|---|---|
| `--text-primary` | `#1A1D21` | 正文、题干 |
| `--text-secondary` | `#5B6470` | 辅助说明、选项次要文字 |
| `--text-disabled` | `#9AA3AE` | 禁用态 |
| `--bg-page` | `#F5F6F8` | 页面背景 |
| `--bg-card` | `#FFFFFF` | 卡片、列表项背景 |
| `--border-color` | `#E4E7EC` | 分割线、输入框边框 |

### 科目识别色

四个科目各有一个固定色,用于列表左侧色条和统计图表,避免看错科目:

| 科目 | 变量 | 值 |
|---|---|---|
| 马克思主义基本原理概论 | `--subject-mayuan` | `#E5484D` |
| 中国近现代史纲要 | `--subject-shigang` | `#F5A524` |
| 习近平新时代…概论 | `--subject-xigai` | `#2F6FED` |
| 英语(专升本) | `--subject-english` | `#12A150` |

科目色不写死,由 `subject.color` 字段存十六进制值,后端返回什么就用什么。

### 暗色模式

`prefers-color-scheme: dark` 时切换:`--bg-page: #12141A`、`--bg-card: #1C1F26`、`--text-primary: #F2F4F7`、`--border-color: #2A2F38`。语义色适当提亮(如 `--color-primary: #5B8DEF`)。

## 三、字体与排版

```css
--font-family: -apple-system, "PingFang SC", "Microsoft YaHei", "Helvetica Neue", sans-serif;
--font-mono: "SF Mono", Consolas, "Courier New", monospace;
```

中文优先用系统字体,不引入 Web Font——省流量、启动快、不闪字。

| 用途 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 页面标题 | 20px | 600 | 1.4 |
| 卡片标题 | 16px | 600 | 1.5 |
| **题干** | **17px** | **400** | **1.75** |
| 选项文字 | 16px | 400 | 1.6 |
| 正文/说明 | 14px | 400 | 1.7 |
| 辅助文字 | 12px | 400 | 1.5 |
| 大数字(统计) | 32px | 700 | 1.2 |

**题干是页面里最重要的一行**,字号比正文大、行高最宽(1.75),因为长题干要读得舒服。题干中英文混排时数字用 `--font-mono`。

## 四、间距与圆角

8px 基准栅格:

```css
--space-xs: 4px;
--space-sm: 8px;
--space-md: 16px;
--space-lg: 24px;
--space-xl: 32px;

--radius-sm: 6px;    /* 标签、小按钮 */
--radius-md: 10px;   /* 卡片、输入框 */
--radius-lg: 16px;   /* 底部弹层 */
--radius-full: 999px; /* 胶囊按钮、进度条 */
```

页面左右内边距固定 `16px`;卡片内边距固定 `16px`;卡片间距 `12px`。移动端不做横向滚动。

## 五、核心组件

### 选项卡片(最重要)

刷题页的选项不是 Element Plus 的 Radio,而是一个自定义卡片组件,因为要承载「选中 / 正确 / 错误 / 我的选择 / 正确答案」五种状态叠加。

```
┌────────────────────────────────────────┐
│  A   马克思主义哲学的基本问题是…        │   ← 默认态
└────────────────────────────────────────┘

┌────────────────────────────────────────┐
│  B   思维和存在的关系问题      ✓ 正确答案 │   ← 答对:绿底绿边
└────────────────────────────────────────┘

┌────────────────────────────────────────┐
│  C   世界的本原是物质          ✗ 你的选择 │   ← 答错:红底红边
└────────────────────────────────────────┘
```

规则:

- 高度最小 `48px`(手指点击友好),上下内边距 `12px`。
- 左侧选项字母用 `--font-mono`,固定 `28px` 宽,居中。
- 选中态:白底 + `--color-primary` 边框 2px + 浅色底。
- **判定后选项不可再点击**,但正确答案始终用绿色标出——即使答对了,也要让用户看到其他选项为什么错。
- 答错时,在选项下方展开解析区,不需要额外点击。

### 知识点/科目卡片

左侧 4px 色条(科目色)+ 科目名 + 右侧进度数字。

### 进度条

统一用胶囊形,高度 `6px`。颜色按完成度变化:0–59% 主色、60–89% 成功色、90%+ 深绿。**不显示百分比数字**,只显示 `12/20` 这类分数。

### 空状态

每个列表页都要有,文案要给出下一步动作,不要只说「暂无数据」:

- 题库为空 →「还没有题目。从电脑上导入一份真题开始吧」+「查看导入格式」按钮
- 错题本为空 →「还没有错题,继续保持」
- 无到期复习 →「今天的复习都做完了,明天见」

### AI 老师抽屉

- 手机端从底部弹出(圆角 `--radius-lg`),桌面端从右侧滑入,宽度不超过 420px。
- 顶部一行:「AI 老师 · 自考辅导」+ 关闭按钮。
- 正文 15px / 行高 1.7,长文本读得舒服;生成中显示三行骨架块。
- 底部一行小字:「内容由 AI 生成,请结合教材核对」+「重新生成」文字按钮(主色)。
- 失败态:一句话原因 + 「重试」,不用大面积红色警告。
- 打开时背景遮罩 40% 黑,点击遮罩可关闭。

### 底部导航(移动端)

四个 Tab:`今日` / `题库` / `错题` / `统计`。图标 + 12px 文字,当前 Tab 用主色。桌面端收起为左侧栏。

## 六、页面布局

### 今日页(首页)

从上到下:日期与考试倒计时 → 连续天数卡片 → 今日主任务大按钮(「开始今日 12 题」)→ 分科目到期数量列表 → 最近一次练习的正确率。

**主任务按钮必须是页面上最大的可点击元素**,高度 `56px` 以上。

### 刷题页

固定三段式:顶部进度(`3/12` + 退出)、中部题干与选项(可滚动)、底部操作区(「确认」/「下一题」)。

答题后底部按钮文案从「确认」变为「下一题」,不新增按钮位置——让手指不用移动。

### 统计页

先给三个大数字:总题量、平均正确率、连续天数。下面是各科目正确率横向条形图、近 30 天趋势折线图。图表用 ECharts(Element Plus 生态兼容好)或轻量的 Chart.js,**不要自己画 SVG**。

## 七、交互细节

| 场景 | 规则 |
|---|---|
| 提交答案 | 选中选项后底部按钮激活;点击后立即判定,不做二次确认 |
| 答错 | 选项变红 + 正确项变绿 + 解析自动展开,不弹窗 |
| 主观题 | 展示参考答案要点,提供「我答到了几点」勾选框,勾选数即得分比例 |
| 中途退出 | 保留本次进度,下次进入询问「继续上次练习吗」 |
| 加载中 | 用骨架屏,不用转圈 |
| 请求失败 | 页面顶部一条可关闭的横条提示 + 「重试」,不用 alert |
| 删除确认 | 只有删除题目/科目才二次确认,其余操作直接执行 |

## 八、响应式断点

| 断点 | 布局 |
|---|---|
| `< 768px`(手机) | 单列,底部 Tab 导航,页面内边距 16px |
| `768–1024px`(平板) | 单列但最大宽度 `720px` 居中 |
| `> 1024px`(桌面) | 左侧栏导航 + 内容区最大宽度 `960px` 居中 |

题库管理、批量导入这类页面允许在桌面端做多列,但**刷题页在所有尺寸下都是单列**,保证注意力集中。

---

## 九、无障碍与细节

- 所有可点击元素最小 `44×44px`。
- 正文对比度不低于 4.5:1。
- 输入框、按钮都要有清晰的 `:focus-visible` 焦点环(主色 2px)。
- 选项字母不只用颜色区分状态,必须同时有图标(✓ / ✗),照顾色觉差异。
- 字号跟随系统设置,不使用 `px` 固定页面根字号之外的 `rem` 换算。
