## 二、各页面职责

### TodayView(今日)

**这是整个应用的门面,必须做到「打开即知该做什么」。**

从上到下:

1. **日期 + 考试倒计时**:「距《马原》考试还有 9 天」(取最近的未考科目)。
2. **连续打卡卡片**:大数字天数 + 「今天已打卡 / 今天还没打卡」。
3. **今日主任务按钮**(页面最大的元素,高度 ≥56px):
   - 有到期复习题 →「开始今日 12 题」
   - 无到期题 →「随机练 10 题」
4. **分科目到期数量列表**:科目色条 + 科目简称 + 「5 题到期」,点击直接进入该科目的复习练习。
5. **最近一次练习**:日期 + 得分 + 正确率,点击可回看详情。
6. **空状态**:题库为空时,主按钮变成「先去导入题库」,跳 `/questions/import`。

**交互要求**:点击主任务按钮后,直接开始第一题,**中间不加确认弹窗**。

**若存在未完成的场次**:页面顶部出现一条提示「上次练习还剩 6 题未做完,继续?」+「继续」/「忽略」。

### CustomPracticeView(自由练习)

按「题源(题库 / 错题)+ 科目 + 题型 + 题量」抽题。进入页面时自动带入
「设置 → 自由练习默认设置」里对应题源的条件,用户不用每次重选;切换题源时自动换成该题源的默认值,
仍可临时修改。「开始练习」按当前条件进入 `/practice/random` 或 `/practice/wrong`。

### PracticeView(刷题)

`mode` 参数决定组题方式,页面结构一致,只有标题不同。

三段式布局:

```
┌─────────────────────────────────────┐
│  ← 退出      3 / 12   ▓▓▓░░░░░░░     │  顶部:返回、进度、进度条
├─────────────────────────────────────┤
│                                     │
│  【单选题 · 2分 · 马原】             │  题型标签
│                                     │
│  马克思主义哲学的基本问题是（  ）    │  题干(17px/行高1.75)
│                                     │
│  ┌───────────────────────────────┐  │
│  │ A  物质和意识的关系问题        │  │  选项卡片
│  └───────────────────────────────┘  │
│  ┌───────────────────────────────┐  │
│  │ B  思维和存在的关系问题        │  │
│  └───────────────────────────────┘  │  ↓ 可滚动
│  ┌───────────────────────────────┐  │
│  │ 解析(判定后展开)             │  │
│  └───────────────────────────────┘  │
├─────────────────────────────────────┤
│  [ 不知道 ] [ 提交答案 ] → 判定后 [ 下一题 ] │  底部操作区,固定不动
└─────────────────────────────────────┘
```

**关键交互:**

- **点选项即判定**:单选 / 阅读选择 / 判断 / 阅读判断点一下选项就直接提交,不再需要「确认」;多选与填空仍需点「提交答案」(填空框回车也可提交)。
- **答对自动下一题**:判定后短暂展示结果(1.2 秒)自动进入下一题,期间也可手动点「下一题」;**答错停留在当前题**,由用户自己点「下一题」,给足看解析的时间。
- **「不知道」**:以空答案提交,立即展示正确答案与解析,并把这道题记入错题本(`wrong_count +1`);主观题点「不知道」按 0 分自评,同时展开参考答案。
- 主观题(`SHORT_ANSWER`/`ESSAY`/`MATERIAL_ANALYSIS`/`WRITING`):底部换成多行输入框 + 「对照答案要点」按钮;判定后展示 `answerPoints` 与参考答案文本,每条要点前有复选框,勾选即计入 `selfScore`,底部出现「提交自评」。
- **「问 AI 老师」**:判定后在解析区底部提供该按钮,点击弹出底部抽屉展示 AI 精简解析;请求携带本题 ID 与你的错选,首次显示「正在联系老师…」骨架,命中缓存秒开,可「重新生成」。AI 不可用时降级显示原解析并给「重试」,**不影响继续答题**。
- 最后一题答对后自动结束并跳 `/practice/:mode/result/:sessionId`;结束场次失败时停留在当前题并提示重试。

**退出处理**:点击退出弹确认「本次练习已自动保存,确定退出?」,确认后回到上一页。

### ResultView(本轮小结)

大数字:得分 / 满分、正确率、用时。下方:本轮错题列表(题干预览 + 科目标签),可点「立即复习错题」再开一轮 `REVIEW` 模式。底部:「再来一轮」「回到今日」。

### QuestionListView(题库管理)

电脑端为主。顶部筛选栏:科目下拉、章节下拉、题型下拉、年份下拉、关键词搜索框。下方 Element Plus 表格:题干摘要(超长省略)、题型、科目、章节、来源、分值、状态。

表格首列可勾选。勾选后表格上方出现批量操作条:
- **批量入库**:把选中的「待校对」题改为「已入库」,入库后进入练习抽题池;
- **AI 生成解析**:对选中的「主观题 + 有参考答案要点 + 还没有解析」的题逐题调用 AI,生成后直接保存。

行操作:编辑 / 删除(删除需二次确认)。工具栏:「新建题目」「批量导入」「导出为 JSON」。底部标准分页。

### QuestionEditView(新建 / 编辑)

表单字段与 `POST /questions` 请求体一一对应:

- 科目(必选)、章节(可选,级联科目)
- 题型(必选,选择后表单动态变化)
- 题干(多行文本,必填)
- **选项区**:仅客观题显示。可增删选项,自动编号 A/B/C/D…;每个选项一个输入框。
- **正确答案**:**单选用一组 Radio,多选用一组 Checkbox**——让用户点选而不是手打字母,避免「答案写成小写 a」这类错误。
- 参考答案要点:仅主观题显示。可增删的文本行列表。
- **解析**:主观题且有要点时,标签旁提供「AI 生成」:按要点生成一段简洁好记的解析填进输入框,
  保存时随题目一起落库;已有解析时会先确认再覆盖。
- 难度(三档)、来源、年份、分值、状态。

**保存前必须做前端校验**,并给出定位到具体字段的错误提示。

### QuestionImportView(批量导入)★

两步式:

1. **上传/粘贴** —— 支持上传 `.json` 文件,或直接粘贴 JSON 文本;再加一个「或粘贴试卷文本」的折叠区域(调用 `/questions/parse-preview`)。
2. **预览确认** —— 解析后展示预览表格:题号、题型、题干摘要、是否校验通过。校验不通过的条目**用红色标出并显示原因**,可选择「跳过这些条目继续导入」或「返回修改」。

导入完成后展示结果卡片:「成功导入 38 题,跳过 2 题」,并列出跳过的条目与原因。

页面右侧固定一个「导入格式说明」抽屉,展示 `03-api-spec.md` 第五节的 JSON 示例(可直接复制)。

**这个页面是录题的入口,易用性优先级最高。**

### WrongBookView(错题本)

列表按科目分组,每条:题干预览、错误次数、连续答对进度(x/3)、下次复习时间、掌握度阶段(未掌握 / 复习中 / 已掌握)。

筛选:科目、题型、是否到期、是否已掌握。顶部「今日到期」+「开始刷题」:
按当前科目 / 题型直接从错题池随机抽题练习(不看到期);勾了「只看已到期」则只练排期到期的题。
操作:立即复习、标记为已掌握、移出。**连续答对 3 次自动置为已掌握,从默认列表移除**
(切到「已掌握」仍能看到;之后再答错会回到未掌握)。每条错题另提供「问 AI 老师」与「举一反三」(阶段 9)。

### StatsView(数据看板)

1. 三个大数字:累计答对题数、平均正确率、连续打卡天数。
2. 各科目正确率横向条形图(科目色)。
3. 近 30 天答题量 + 正确率趋势(折线图,双 Y 轴)。
4. 章节掌握度(选择科目后展示,用于找薄弱章节)。

图表用 ECharts 按需引入,数据来自 `/stats/*`。

### DigestView(考前串讲)

选择科目 → 「生成 / 重新生成」按钮 → 展示「必背 N 点」清单(卡片式分点,可逐条勾选「已背会」)→ 支持一键复制全部。已生成过的科目进入即显示缓存版本,点「重新生成」才覆盖。

### SubjectListView(科目与章节)

左右两栏(桌面端):左侧科目列表,右侧该科目的章节树。支持增删改。科目表单包含课程代码、全称、简称、标识色(取色器)、考试日期、考试场次(四选一下拉)。

### SettingView(设置与提醒)★

分四块:

1. **学习设置** —— 每日题量(数字输入,默认 10)。
2. **自由练习默认设置** —— 默认题源(题库 / 错题);两个题源分别配置默认科目、题型、题量。
   进入自由练习时自动带入,不用每次重选。
3. **提醒设置** —— 早间提醒开关 + 时间选择、晚间未打卡提醒开关 + 时间、「发送测试提醒」按钮(调 `POST /notify/test`,微信里真实收到)。
4. **通道配置** —— 通道选择(企业微信群机器人 / Server酱)、Webhook 或 SendKey 输入(保存后仅显示掩码,如 `…a1b2c3`)、近 7 天提醒日志(日期、类型、成功/失败原因)。

**这一块是「提醒刚需」的落地面**,配置必须可实测:点「发送测试提醒」后如实反馈发送结果(成功或失败原因),不允许出现「显示已开启却永远收不到」的状态。

## 三、导航结构

**移动端底部 Tab**(4 项):

| Tab | 图标 | 路由 | 角标 |
|---|---|---|---|
| 今日 | 首页 | `/` | 到期题数 |
| 题库 | 列表 | `/questions` | — |
| 错题 | 书签 | `/wrong` | 到期复习数 |
| 统计 | 图表 | `/stats` | — |

科目管理、设置通过今日页右上角进入(不占 Tab 位)。

**桌面端左侧栏**:今日 / 题库 / 错题 / 统计 / 科目 / 导入 / 设置,平铺全部入口。

## 四、空状态文案(统一规范)

| 页面 | 文案 | 按钮 |
|---|---|---|
| 题库为空 | 还没有题目。从导入一份真题开始吧。 | 查看导入格式 |
| 错题本为空 | 还没有错题,继续保持。 | 去刷题 |
| 今日无到期 | 今天的复习都做完了,明天见。 | 随机练 10 题 |
| 统计无数据 | 还没有练习记录,做几道题这里就有数据了。 | 开始刷题 |
| 搜索无结果 | 没有找到匹配的题目,换个关键词试试。 | 清空筛选 |
